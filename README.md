# MercuryModder
Lets you mod your fridge in a much easier way.

This tool works with the assumption that you have two copies of your game - a clean one and a "dirty" (modded one). It uses the clean copy as a template to produce files which are then written over the "dirty" version.
You probably want to check out [the guide](./GUIDE.md) for basic usage with custom charts. Other parts are not really documented but you can contact me on discord if you encounter any issues with those.

Big thanks to everyone in that one Discord server for all the help when writing and debugging this and numerous other things.
